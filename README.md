## 1. Descripción del Proyecto y Justificación

* **Banco de Proyectos de Origen:** [App Ideas (Tier 1: Beginner)](https://github.com/florinpop17/app-ideas)
* **Descripción:** `Hello.App` es una aplicación básica de interacción de usuario orientada a la gestión y bienvenida personalizada de perfiles dentro de una plataforma inicial.
* **Justificación de la necesidad:** Resuelve la necesidad de ofrecer un módulo centralizado e intuitivo de registro, saludo e interacción básica para usuarios de un sistema en fase de prototipado.

---

## 2. Historias de Usuario (User Stories)

* **US01 - Saludo Personalizado:** Como usuario, quiero ingresar mi nombre para recibir un saludo personalizado en pantalla.
* **US02 - Configuración de Preferencias:** Como usuario, quiero seleccionar mi tema de interfaz (claro/oscuro) para adaptar la experiencia a mis gustos.
* **US03 - Contador de Visitas:** Como usuario, quiero ver cuántas veces he interactuado con la aplicación durante la sesión actual.

---

## 3. Metodología Elegida y Justificación

* **Metodología:** Ágil (Kanban)
* **Justificación:** Se selecciona un enfoque ágil debido al tamaño reducido del equipo (3-4 integrantes) y al tiempo limitado de desarrollo (2 sesiones). La metodología permite visualizar las tareas mediante un tablero Kanban en GitHub Projects, adaptándose rápidamente a ajustes en las historias de usuario y facilitando la entrega continua de avances funcionales.

## 5. Retrospectiva del Equipo (Cierre)

| Aspecto | Observación |
| :--- | :--- |
| **Qué funcionó bien** | La integración de GitHub Projects para organizar los Issues y la comunicación directa al dividir las Historias de Usuario. |
| **Qué no funcionó / Dificultades** | Coordinar los tiempos para sincronizar los primeros commits y definir el alcance exacto del modelado inicial. |
| **Qué haríamos distinto** | Asignar etiquetas (*labels*) más detalladas en GitHub Projects desde el primer momento y automatizar el cierre de Issues mediante los commits. |
